# 단지계획 벼락치기

대학 「단지계획(Site Planning)」 과목 1~3주차 시험 대비용 정적 학습 사이트입니다.
설치·빌드 없이 `index.html` 하나로 동작하며, GitHub Pages로 배포됩니다.

**바로 열기: https://sngb05.github.io/danji-plan-study/**

## 기능

| 탭 | 내용 |
|---|---|
| 📖 정리 | 주차별·소단원별 핵심 요약 (읽음 체크로 진행률 관리) |
| 🃏 카드 | 플래시카드. 모름/알겠음 분류, 모름 카드 자동 재등장 |
| ✏️ 퀴즈 | 객관식·빈칸·O/X·키워드 회상. 오답노트 자동 저장 |
| 📊 비교표 | "A vs B" 서술형 대비 비교표 모음 |
| 🔢 숫자 | 거리·비율·연도·법조문 등 숫자만 모아 빈칸 암기 |

- 진행 상태는 브라우저 `localStorage`에만 저장됩니다.
- 키보드: `Space` 카드 뒤집기, `←`/`→` 모름/알겠음, `1`~`4` 보기 선택, `Enter` 다음.
- 다크모드는 시스템 설정을 따르며 우측 상단 버튼으로 전환할 수 있습니다.

## 구조

```
index.html        UI (HTML + CSS + JS, 외부 의존성 없음)
data/unit1.js     1주차 단지의 개념과 유형
data/unit2.js     2주차 단지계획의 의미·목적과 계획 과정
data/unit3.js     2주차 근린주구론
data/unit4.js     3주차 동선체계
data/unit5.js     3주차 오픈스페이스 체계 · 건축물 배치와 밀도·형태
```

원본 강의자료(PDF)는 저작권 관계로 저장소에 포함하지 않습니다.
